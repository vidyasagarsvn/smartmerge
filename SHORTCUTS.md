# SmartMerge Keyboard Shortcuts

All shortcuts are **platform-aware** and adapt to your operating system:

## File Menu

| Action | Linux/Windows | macOS |
|--------|---------------|-------|
| Open Files | Ctrl+O | Cmd+O |
| Open Folders | Ctrl+Shift+O | Cmd+Shift+O |
| Back to Folder View | Ctrl+B | Cmd+B |
| Exit | Ctrl+Q | Cmd+Q |

## Edit Menu

| Action | Linux/Windows | macOS |
|--------|---------------|-------|
| Font | Ctrl+Shift+F | Cmd+Shift+F |

## Navigation Tips

1. **Opening Files**: Use Ctrl+O (or Cmd+O on macOS) to open two files for comparison
2. **Opening Folders**: Use Ctrl+Shift+O (or Cmd+Shift+O) to browse and compare folders
3. **Navigating Folders**: Double-click any folder that appears on both sides to open it
4. **Comparing Files**: Double-click any file to see the diff between the two versions
5. **Going Back**: When viewing a file from folder context, use Ctrl+B (or Cmd+B) to return to folder view
   - The "Back to Folder View" option is only enabled when navigating from the folder view

## Diff Navigation

| Action | Linux/Windows | macOS |
|--------|---------------|-------|
| Next Change | Alt+Down | Option+Down |
| Previous Change | Alt+Up | Option+Up |

## Folder Comparison Features

- **Non-recursive by default**: Shows only root-level items
- **Bi-presence navigation**: Folders can only be opened if they exist on both sides
- **Visual indicators**: 
  - ✓ Green = Identical items
  - ≠ Yellow = Modified items
  - Grayed out = Single-side items (cannot be navigated)

## Tips

- All shortcuts automatically adapt to your keyboard layout
- On macOS, Cmd is used instead of Ctrl
- Context menus are available via right-click for additional actions
