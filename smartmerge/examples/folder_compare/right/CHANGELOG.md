# SmartMerge Changelog

## [0.2.0] - 2026-02-12
### Added
- Folder/directory comparison feature
- Non-recursive folder navigation
- Table-based folder view with status indicators
- Breadcrumb navigation support (prepared)
- Unit tests for folder comparison

### Changed
- Updated UI to use stacked widget for file/folder views
- Improved status bar messaging
- Enhanced keyboard shortcuts documentation

### Fixed
- Fixed Myers diff algorithm opcode bounds checking
- Corrected highlighting logic for inserts/deletes

## [0.1.0] - 2026-02-01
### Added
- Initial release
- File comparison with side-by-side view
- Myers diff algorithm implementation
- Full-line highlighting with color coding
- Font selection dialog
- Recent file persistence
