# Project Documentation

## Overview
This is a sample project for testing folder comparison features.

## Features
- File comparison
- Folder comparison
- Diff highlighting
- Cross-platform support
- 3-way merge support
- Binary file support

## Installation
Run `pip install smartmerge` to install the package.

## Usage
Launch the application with `smartmerge` command from terminal.
